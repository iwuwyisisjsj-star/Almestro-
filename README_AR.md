# إدارة محل الهواتف — نسخة ويب عربية

## الميزات الحالية
- واجهة عربية RTL متجاوبة مع الهاتف.
- إدارة الصيانة وتغيير الحالة والبحث.
- إدارة المخزون، حد التنبيه، زيادة/نقصان الكميات وتسجيل بيع يخصم المخزون.
- تسجيل الهواتف الجديدة والمستعملة وتغيير حالتها إلى تم البيع.
- لوحة مؤشرات ومبيعات أصناف اليوم.
- تصدير واستيراد نسخة احتياطية بصيغة JSON.
- PWA: manifest وservice worker لتوفير ملفات الواجهة بعد تحميلها أول مرة.

## تشغيلها على الهاتف
1. ارفع الملفات إلى استضافة HTTPS ثابتة مثل GitHub Pages أو خدمة استضافة ملفات ثابتة موثوقة. لا تفتح index.html مباشرة من مدير الملفات؛ بعض خصائص PWA تحتاج HTTPS.
2. افتح رابط `index.html` في Chrome على أندرويد.
3. جرّب تسجيل صنف وجهاز صيانة، ثم صدّر نسخة احتياطية.
4. من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إن ظهرت.
5. افتح التطبيق من الأيقونة. يجب فتح الرابط مرة واحدة على الأقل مع الإنترنت لتخزين ملفات الواجهة.

## التخزين والخصوصية
البيانات تحفظ في localStorage الخاص بالمتصفح/التطبيق على هذا الجهاز، وليست في قاعدة بيانات سحابية. لا تمسح بيانات الموقع أو المتصفح؛ ذلك قد يحذف البيانات. صدّر النسخة الاحتياطية دوريًا واحفظها في مكان آمن. لا توجد مزامنة بين الأجهزة. الاختبار مطلوب قبل الاعتماد التجاري.

## تحويل نسخة الويب إلى APK لاحقًا
النسخة الحالية PWA وليست APK. لإنشاء APK، تحتاج تغليفًا موثوقًا مثل Trusted Web Activity مع Android Bubblewrap، أو مشروع Android WebView موقّع. غالبًا يتطلب ذلك بيئة بناء Android/Gradle أو خدمة بناء سحابية، ورابط HTTPS منشورًا. التثبيت من الشاشة الرئيسية لا ينشئ APK مستقلًا.
